Implementation Note: The proposed dark mode colors follow the same pattern as the existing Main Menu dark mode. Each dark variant is approximately 25-30% of the brightness of the light mode color, maintaining the same hue family. The ThemeManager's gradient formulas will automatically derive the three-color gradients (darkBurgundy → base → darkPurple) for each dark mode base color.
Color Derivation Formula: Dark mode base colors were calculated by reducing RGB values by approximately 70-75% while maintaining color temperature and hue relationships. This ensures visual consistency across all screens while providing proper contrast in dark mode.
